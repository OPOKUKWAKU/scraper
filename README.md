Quotes Scraper 📝

A simple Python web scraper that collects quotes, authors, and tags from Quotes to Scrape.

Features
Login handling with Requests sessions.
Extracts CSRF tokens dynamically.
Scrapes multiple pages automatically.
Extracts quotes, authors, and tags.
Exports scraped data to CSV.

Technologies
Python
Requests
BeautifulSoup4
CSV

Installation
pip install requests beautifulsoup4

Usage
python scraper.py

Scraped data is saved in man.csv.

What I Learned
HTTP GET and POST requests.
Session and cookie management.
Login forms and CSRF tokens.
HTML parsing with BeautifulSoup.
Pagination and CSV export.
